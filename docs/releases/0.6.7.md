# Bosun 0.6.7

The visual setup guide is now part of Bosun. Choose your configuration, follow
its wiring diagram and installation steps, then check MIDI and Stage together.
All new setup screens, instructions and FAQs are in English.

## What changed

- Six illustrated configurations: Captain directly to Kemper Player; Android
  hub and Stage; Desktop hub and Stage; Pi 3; Pi with HDMI; Pi with Android over Wi-Fi.
- Desktop first installation goes directly from factory firmware to
  **0.6.7-native**, with explicit device/model confirmation, a verified full
  flash backup before writing, readback checks and recovery support. No older
  Bosun release or CircuitPython bootstrap is needed.
- Guided Raspberry Pi setup exports a package with prebuilt Stage and generates
  the transfer/install command. Raspberry Pi Imager still prepares the OS card;
  Desktop does not write the card itself.
- The same setup guide is available as an offline HTML download and beside the
  Windows executable.
- Per-profile bank layout: 1–10 rigs per bank and 1–99 banks. Captain bank
  navigation, editor and Stage use the configured layout; saved patches remain available.
- Optional Pi boot branding includes the Bosun logo, version and progress
  milestones, with a guarded trial before making the early splash permanent.
  The fresh-card installer does not enable early boot branding automatically.

## Compatibility and validation

The native installation target is the **10-switch RP2040 MIDI Captain with
8 MiB flash**. The setup diagrams target **Kemper PROFILER Player**. Factory
installation creates empty Bosun profiles; the original factory settings stay
in the full backup. Existing native updates preserve configuration; existing
Bosun CircuitPython profiles migrate through the Pi updater.

The factory-to-native installer is experimental: automated software tests and
build checks do not replace end-to-end validation on a factory Captain, which
is still pending. Fresh Pi card installation also needs hardware validation.
**macOS and Linux apps remain untested on real systems.** Keep the verified full
backup created by the installer. Release builds are published only after the
automated release gate, native tests and all four platform builds succeed.
