# Bosun 0.7.0 — experimental PROFILER support

This prerelease adds one shared Kemper PROFILER plugin for Head, Rack and Stage,
alongside the existing Player plugin. Physical Head/Rack/Stage validation is
pending. Version 0.6.10 remains the stable release.

- Choose your Kemper model, USB or two-cable DIN, host and display in the setup
  guide. Raspberry Pi with HDMI and Android with Stage are included. PROFILER
  generation and mode carry into profile creation.
- Select all 125 Performances and five slots, or assigned Browse programs 0–127.
  Optional Browse mappings follow external program changes without replaying
  patch entry actions.
- Store and navigate up to 625 configured patches. Patch lists are paginated
  for the editor, Stage and update backups.
- Share effect, tuner, Morph, looper and feedback code between Kemper models.
  MK1/MK2 command availability follows the selected configuration.
- Query MIDI identity in Settings. Unknown model/OS identifiers and operating
  mode remain manual; the probe never guesses or changes capabilities.

## Before upgrading

Use matching Desktop, native Captain firmware and Pi/Stage assets from this
prerelease. Keep the full-flash backup made before updating.

Storage expands from 512 KiB to 4 MiB on the first configuration write, preserving
the original blocks. After expansion, **downgrading requires restoring the
full-flash backup**; an older UF2 alone cannot read the expanded filesystem.
Actual capacity depends on patch sizes and other profiles sharing storage.

Automated validation covers real littlefs storage of 625 representative patches,
interrupted writes during expansion, paginated inventories, protocol encodings,
profile separation and editor/Stage flows. Hardware testing was deliberately
excluded. macOS and Linux application operation remains unverified.

See the [PROFILER setup and limitations](https://github.com/danmigdev/bosun-midi-captain/blob/v0.7.0/docs/kemper-head.md)
for connections, supported commands and the pending hardware checks.
