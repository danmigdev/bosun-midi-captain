# Bosun 0.8.1: fixes and a native-only project

## Fixes

- **Raspberry Pi installation works again on a fresh card.** Since 0.7.0 the
  installer stopped halfway because it compiled a converter that needed a file
  only the firmware build generates. The Pi no longer compiles anything, so the
  installer no longer needs build tools either.
- **Deleting a patch keeps your other unsaved edits.** It used to discard
  pending edits on every patch, not only on the one being deleted.

## Native firmware only

Bosun ran on CircuitPython before the native firmware arrived in 0.6.5. What
remained of that firmware is gone:

- Desktop no longer offers CircuitPython file updates or a GitHub release check
  for them. An unflashed pedal (factory firmware or bootloader drive) still opens
  the native installer.
- The Raspberry Pi no longer migrates CircuitPython installations. Updating
  through the Pi covers native firmware, with the same backup, verification and
  rollback as before.
- Downloads no longer carry the CircuitPython UF2 or its libraries, so the
  desktop and Android packages are smaller.
- Releases older than 0.6.5 were removed from GitHub.

The Kemper PROFILER profile type is now labelled
**Kemper PROFILER - Head / Rack / Stage (experimental)**.

Developers: the native build reads its message schemas from
`firmware-native/schemas/`, and the `firmware/` tree, the CircuitPython test
battery, the comparison tests and the related scripts were removed. The
repository also lost a set of unused scripts, samples and icons, and the unused
Tauri shell plugin.

## Before upgrading

Use matching Desktop, native Captain firmware and Pi/Stage assets. Keep the
verified full-flash backup that the update creates. Pi hubs pick up the change
by installing the 0.8.1 Pi setup package. See
[firmware update and recovery](../firmware-updates.md).
