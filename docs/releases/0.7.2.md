# Bosun 0.7.2: stable Tauri and F-Droid-ready Android builds

This maintenance release changes how Bosun is built, not how it behaves.
Features and Captain firmware behavior match 0.7.1, and the Kemper family
support remains experimental.

- Bosun now uses the stable Tauri 2.12 release instead of a pinned
  development commit, keeping the official reproducible-build fixes.
- The Android APK is reproducible from source by F-Droid: the packaged Tauri
  configuration is now written in a fixed order. The release workflow also
  rebuilds the desktop RP2040 flash ID helper from source and checks its hash.
- The Android store descriptions (English and Italian) describe the current
  app.

## Before upgrading

Use matching Desktop, native Captain firmware and Pi/Stage assets. Keep the
verified full-flash backup created before upgrading. The 0.7.1 notes on
configuration storage and downgrades still apply.

See [what changed in 0.7.1](https://github.com/danmigdev/bosun-midi-captain/blob/v0.7.2/docs/releases/0.7.1.md)
and [Android reproducible builds](https://github.com/danmigdev/bosun-midi-captain/blob/v0.7.2/docs/android-reproducible-builds.md).
