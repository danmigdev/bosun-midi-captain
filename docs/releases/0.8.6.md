Bosun 0.8.6 updates the Raspberry Pi from Bosun Desktop, without SSH, and adds
a screensaver with your logo on the Captain TFT and the Stage display.

## Changes

- **Update the Raspberry Pi from Desktop.** Maintenance > "Update Bosun" in
  Bosun Desktop, connected through a Raspberry Pi, now updates the Pi first
  and then the Captain firmware. No SSH or password is needed.
  - The Pi installs only packages signed with the Bosun release key, and never
    a release older than the one it runs. The signature is checked before
    anything is unpacked.
  - If the new version does not start correctly, the Pi restores the previous
    one by itself and Desktop says so. An update cut short by a power loss is
    undone at the next start.
  - A Pi that already has every system package it needs updates without an
    Internet connection.
  - **Once:** a Pi running 0.8.5 or older does not know this yet. Update it to
    0.8.6 one last time with the Setup guide command; from then on Desktop
    updates it. Updating the Pi stays a Desktop feature; Android is unchanged.
- **Screensaver.** In Settings > Display, "Screensaver after (minutes)" turns
  it on (0, the default, keeps it off) and "Screensaver effect" chooses
  Bounce, Breathe, Drift or Mix, which changes effect every minute. "Show now"
  previews it. The Captain TFT and a Raspberry Pi Stage display show the
  startup logo with the same effect.
  - The first switch press only wakes the screens: it does not change the
    patch, toggle an effect or send MIDI. A tap on the Stage also only wakes
    them.
  - A rig or patch change, turning the Kemper tuner on or off, and changes
    made from Bosun Desktop or Android wake them too. Moving an expression
    pedal does not.
  - While the firmware is updated, the "Updating" screen replaces the
    screensaver.

Update the Raspberry Pi first (see above), then the app and the Captain
firmware. The screensaver settings appear once the Captain runs 0.8.6.

## Downloads

| System | Package | Installation |
| --- | --- | --- |
| Windows x64 | `Bosun-<version>-portable-x64.zip` | Extract the whole ZIP and run `Bosun.exe`. Requires WebView2. |
| macOS, Apple Silicon (untested) | `.dmg` | Open it and copy Bosun to Applications. |
| Linux x64 (untested) | `.AppImage` | Make it executable, then open it. |
| Android 10 or later | `bosun.apk` | Install the APK; connect over USB-OTG or through a Pi hub. |

The release also carries the offline setup guide
(`Bosun-0.8.6-setup-guide.html`), the Raspberry Pi setup package
(`Bosun-0.8.6-pi-setup.tar.gz`) with its signature
(`Bosun-0.8.6-pi-setup.tar.gz.sig`), the firmware update package
(`Bosun-0.8.6-firmware-update.zip`), the browser Stage (`Bosun-0.8.6-stage.zip`)
and `SHA256SUMS.txt`.

## Testing

Updating the Pi from Desktop was tested on a Raspberry Pi 3 with a 10-switch
Captain: a full update of the Pi and then the Captain, and a forced failure
that the Pi undid on its own, leaving every installed file as it was. The
screensaver comes with tests in the firmware, Desktop and Raspberry Pi test
suites.

Everything else is unchanged from
[0.8.5](https://github.com/danmigdev/bosun-midi-captain/blob/main/docs/releases/0.8.5.md).
