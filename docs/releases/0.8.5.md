Bosun 0.8.5 lets you put your own logo on the Captain and Raspberry Pi startup
screens, and keeps the pedal still while its firmware is updated. Update the
Raspberry Pi first, then the app and the Captain firmware.

## Changes

- **Your own startup logo.** Settings > Startup logo takes a PNG, JPEG, WebP or
  SVG image and shows it on the Captain TFT at power-on and on the Raspberry
  Pi startup screens, in place of the Bosun icon and name. The Pi keeps the
  version line and the progress bar. "Startup logo (seconds)" sets how long
  the TFT shows it (0 to 60, default 2). "Use Bosun logo" brings the default
  back. The Captain shows the Bosun logo until you choose one.
- **The pedal stays still during a firmware update.** While Bosun Desktop
  updates the Captain, over USB or through a Raspberry Pi, the footswitches do
  nothing, the TFT shows the startup logo with "Updating", and the Pi's Stage
  display shows "Updating" with the current step and a reminder not to unplug
  the Captain or power off the Pi. When you update from 0.8.4, the old
  firmware does not know the lock yet, so the switches stay locked only once
  0.8.5 is running.
- **Tighter file ownership on the Raspberry Pi.** The Pi installer now keeps
  the installed Bosun files owned by root, except the Stage files the hub
  writes. Before, the hub's own account could change files that root uses
  to draw the startup screens.

A Raspberry Pi that still runs 0.8.4 accepts the 0.8.5 firmware package, but
the Pi startup logo and the Stage "Updating" screen need 0.8.5 on the Pi.

## Downloads

| System | Package | Installation |
| --- | --- | --- |
| Windows x64 | `Bosun-<version>-portable-x64.zip` | Extract the whole ZIP and run `Bosun.exe`. Requires WebView2. |
| macOS, Apple Silicon (untested) | `.dmg` | Open it and copy Bosun to Applications. |
| Linux x64 (untested) | `.AppImage` | Make it executable, then open it. |
| Android 10 or later | `bosun.apk` | Install the APK; connect over USB-OTG or through a Pi hub. |

The release also carries the offline setup guide
(`Bosun-0.8.5-setup-guide.html`), the Raspberry Pi setup package
(`Bosun-0.8.5-pi-setup.tar.gz`), the firmware update package
(`Bosun-0.8.5-firmware-update.zip`), the browser Stage (`Bosun-0.8.5-stage.zip`)
and `SHA256SUMS.txt`.

## Testing

The changes come with tests in the firmware, Desktop and Raspberry Pi test
suites. The startup logo was checked on a 10-switch Captain and on a Raspberry
Pi 3 with an HDMI display.

Everything else is unchanged from
[0.8.4](https://github.com/danmigdev/bosun-midi-captain/blob/main/docs/releases/0.8.4.md).
