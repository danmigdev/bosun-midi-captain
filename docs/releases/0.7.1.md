# Bosun 0.7.1 — experimental Kemper family support

This release brings the experimental PROFILER branch into `main`. Bosun now
includes Kemper Player, Head, Rack and Stage profiles. Head/Rack/Stage share
one PROFILER plugin and the common Kemper engine; physical validation of these
models is still pending. This remains an experimental prerelease.

- Choose your Kemper model, connection, host and display in the setup wizard.
  USB and two-way MIDI DIN instructions cover Android, Desktop, Raspberry Pi,
  HDMI displays and Android over Wi-Fi.
- Select Performance slots across all 125 Performances, or Browse MIDI programs
  0–127. Optional Browse mappings follow external program changes.
- Store and navigate up to 625 configured patches, with paginated inventories
  shared by the editor, Stage and update backups.
- Enter RPI-RP2 with **Maintenance → Enter bootloader** over direct USB. Desktop
  checks for unsaved patch edits first.
- Without Desktop, hold **switch 1 (top-left)** alone for **three seconds while
  powering on**. This shortcut requires the new firmware and runs before
  configuration and display initialization.
- Updated documentation and offline setup FAQ cover the Kemper family,
  experimental status, model-specific wiring and stock firmware recovery.

## Before upgrading

Use matching Desktop, native Captain firmware and Pi/Stage assets. Keep the
verified full-flash backup created before upgrading.

Upgrading from 0.6.x expands configuration storage from 512 KiB to 4 MiB on the
first configuration write. Once expanded, **downgrading requires restoring
the full-flash backup**; an older UF2 alone cannot read the expanded filesystem.
The supported Captain is the 10-switch RP2040 model with 8 MiB flash.

Kemper Head/Rack/Stage hardware validation and macOS/Linux application operation
remain unverified. No hardware is flashed by the build or automated tests.
See [PROFILER setup and limitations](https://github.com/danmigdev/bosun-midi-captain/blob/v0.7.1/docs/kemper-head.md)
and [firmware update and recovery](https://github.com/danmigdev/bosun-midi-captain/blob/v0.7.1/docs/firmware-updates.md).
